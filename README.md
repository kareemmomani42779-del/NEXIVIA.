# NEXIVA — AI Complete

هذه النسخة تجمع NEXIVA مع:
- AI حقيقي عبر OpenAI Responses API.
- الاسم والجنس من حساب المستخدم.
- صياغة الواجهة والمدرس حسب الجنس.
- محادثة نصية حقيقية.
- زر ميكروفون للإدخال الصوتي من المتصفح.
- قراءة رد الـAI بصوت المتصفح.

التشغيل:
1. ثبّت Node.js.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى `.env`.
5. ضع مفتاح OpenAI في `OPENAI_API_KEY`.
6. نفّذ `npm start`.
7. افتح `http://localhost:3000`.

لا تضع مفتاح API داخل index.html ولا تنشر ملف .env.
ملاحظة: الحسابات الحالية ما زالت محلية في المتصفح وليست نظام حسابات إنتاجيًا.
